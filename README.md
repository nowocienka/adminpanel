# Admin Dashboard

Admin Dashboard is a React-based administration interface designed for presenting and managing data through tables, charts and reusable UI components.

The project focuses on building a structured dashboard interface and working with data visualization components.

## Live Demo

[View Admin Dashboard](https://www.kamilnowocien.pl/adminpanel/)

## Features

- Administration dashboard interface
- Data tables using MUI Data Grid
- Charts and data visualization
- Multi-page navigation
- Reusable React components
- Responsive interface

## Tech Stack

- React
- JavaScript
- Material UI
- MUI Data Grid
- Recharts
- React Router
- Sass
